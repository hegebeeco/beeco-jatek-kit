Döntéskártya

Húzd a kártyát balra vagy jobbra (vagy gomb, ←/→) – egyes döntések később visszajönnek.

Kinek: Polgármester egy napra, Greenwashing-stílusú kártyák · js/mech/kartya-*.js

Hogyan használd?
MechKartya.mount(el, { cards, render:c => html, labels:{ left:'Nem', right:'Igen' },
  onDecide:(side, card, kovetkezmeny) => {…}, onEnd:(tortenet) => {…} });
// késleltetett következmény a kártyán: right:{ label:'Igen', then:{ card:{…}, after:2 } }

Rács szomszédsági hatásokkal

Válassz lapkát, koppints egy mezőre – a szomszédok egymásra hatnak, a mérők azonnal mutatják.

Kinek: Élő kert · js/mech/racs-*.js

Hogyan használd?
MechRacs.mount(el, { w:6, h:5, tiles:[{ type:'fa', label:'Fa', icon:'🌳' }],
  values:[{ id:'elohely', label:'Élőhely', icon:'leaf', min:-10, max:20 }],
  rules:{ tiles:{ fa:{ base:{ elohely:2 }, aura:{ radius:1, add:{ ho:-1 } },
                       near:[{ type:'virag', add:{ elohely:1 }, max:2 }] } } } });

Pontok összekötése

Húzz vonalat két pont között (vagy koppints egymás után a kettőre); a vonalra koppintva törlöd.

Kinek: Beporzó hálózat · js/mech/vonal-*.js · kritikus: ha kiesik, szétszakad a háló

Hogyan használd?
const v = MechVonal.mount(el, { nodes:[{ id:'a', x:10, y:20, type:'ret' }], size:[100, 60],
  types:{ ret:{ label:'Rét', icon:'🌼' } }, maxDist:30, maxLinks:8, onChange:(m) => {…} });
v.graph.metrics()  // { components, isolated, critical, bridges, … } · v.remove('a') = zavarás

Kombinálás időzítővel

Húzz egy tárgyat egy másikra – ha összeillenek, új lesz belőlük; a „Következő kör” telik az idő.

Kinek: Ételmentő, Körforgó háztartás · js/mech/kombinal-*.js

Hogyan használd?
MechKombinal.mount(el, { slots:8, items:{ repa:{ label:'Répa', icon:'🥕', fresh:4, spoilsTo:'komposzt' } },
  recipes:[{ a:'repa', b:'krumpli', out:'leves', time:2 }], start:['repa'], supply:['repa'] });
